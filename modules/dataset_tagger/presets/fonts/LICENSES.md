# Fuentes del mini-editor de texto (captioner Ideogram 4)

Set chico de fuentes **libres y redistribuibles** para componer texto sobre los
flyers (Caso A). Todas se incluyen en el repo para portabilidad (Regla 7: nada
depende del sistema). El usuario puede cargar otras desde disco bajo su propia
responsabilidad de licencia.

| Fuente | Familia | Uso típico | Licencia |
|---|---|---|---|
| Anton-Regular.ttf | Anton | títulos display condensados | SIL OFL 1.1 |
| BebasNeue-Regular.ttf | Bebas Neue | títulos all-caps | SIL OFL 1.1 |
| Poppins-Regular.ttf | Poppins | cuerpo / subtítulos sans | SIL OFL 1.1 |
| Poppins-Bold.ttf | Poppins | énfasis sans | SIL OFL 1.1 |
| Pacifico-Regular.ttf | Pacifico | script / acentos | SIL OFL 1.1 |

Origen: repositorio oficial Google Fonts (https://github.com/google/fonts).
La SIL Open Font License 1.1 permite uso, modificación y redistribución
(incluido comercial) siempre que las fuentes no se vendan por sí solas y se
conserve esta atribución. Texto completo: https://openfontlicense.org
